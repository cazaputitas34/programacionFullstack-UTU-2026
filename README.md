Este repositorio reúne ejercicios prácticos y proyectos desarrollados a lo largo del curso, entre ellos trabajos de **HTML**, **CSS**, **Java** y **PHP**, junto con algunos recursos y notas adicionales.

La idea es tener todo en un solo lugar, ordenado y fácil de revisar más adelante.

---

## 📂 Contenido

Hay ejercicios de HTML y CSS (incluyendo uno con Bootstrap), prácticas de Java junto con un parcial resuelto, un ejercicio de PHP con bloques, y un pequeño proyecto web inspirado en *Hello Neighbor*. También hay una carpeta de notas escritas y la configuración del editor.

Cada carpeta lleva el nombre del ejercicio que contiene, así que es fácil encontrar lo que se busca.

---

## 🚧 Estado

Repositorio en constante actualización, a medida que se van sumando nuevos ejercicios.
